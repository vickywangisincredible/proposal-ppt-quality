# PPT 内容与视觉质量 Skill

先理解内容，再匹配视觉表达；保留原始信息，反复核查最终成品。

由 Vicky Wang 的 PPT 制作与修订实践整理，适合优化已有 PPT，以及制作商业提案、市场战略和合作方案。使用中文编写，可交给能够读取中文规则的工作 Agent。

## 下载与使用

- **技能安装包**：[下载 v1.1.0 ZIP](proposal-ppt-quality-v1.1.0.zip?raw=true)
- **没有技能导入功能**：[下载通用指令](PPT优化通用指令.md?raw=true)，与待处理 PPT 一起上传；也可以复制其全文到任务指令。
- **阅读全部规则**：[SKILL.md](SKILL.md)

### 豆包工作等支持本地技能导入的 Agent

在当前客户端的技能管理入口选择导入本地技能文件，上传上述 ZIP。具体入口、权限和包校验以实际客户端为准。若无法导入，使用通用指令方式。

本项目已检查文件结构和压缩包完整性，尚未在豆包工作客户端完成实际安装与执行测试。导入成功后，建议用允许分享的短 PPT 验证内容保留、可编辑性及最终显示效果。

### Codex 或支持 SKILL.md 目录的 Agent

ZIP 内包含 `proposal-ppt-quality/` 技能文件夹；也可将仓库中的 `SKILL.md` 和 `LICENSE` 放进同名文件夹，再按目标 Agent 的当前文档安装到支持的技能目录。仓库首页和构建脚本不需要安装。

使用时指定 `$proposal-ppt-quality`，或用自然语言明确要求采用此技能。

## 它提供什么

- **内容保真**：默认优化视觉与排版，未经授权不改写原文、数字、单位、口径、限定条件和结论。数据有矛盾时保留原值并标注待核对。
- **内容驱动设计**：先明确每页的问题与关系，再选择图解。图标、卡片与箭头不能代替逻辑表达。
- **数据图选择指南**：覆盖比较、趋势、组成、分布、关联、增减、阶段流失、流向、目标、矩阵、地图和查数；写明图型条件及误导风险。
- **品牌与字体适配**：学习当前项目的品牌；协调中文、东亚文字、英文和数字字体，检查实际导出及压缩后的 PDF。
- **重复验收**：至少两轮全套审阅；修复后重新导出、复查受影响页面，最终交付文件须实际渲染并逐页查看。

例如，曝光规模与互动成本可以用散点图同时比较；没有真实第三指标时，各点大小统一。曝光、阅读、互动若不是同一批对象的嵌套阶段，不应直接画成转化漏斗。

## 示例任务

### 优化已有 PPT

> 请使用 proposal-ppt-quality 优化这份 PPT，受众是客户管理层，用于会议讲解和会后阅读。保留全部原文、数据和结论，可以按逻辑拆页。先理解每页的核心关系，再选择图表与布局。采用我提供的品牌资料。完成后反复核查并验收最终可编辑 PPTX；同时需要 PDF。说明实际完成的检查与未解决的问题。

### 根据材料制作新提案

> 请使用 proposal-ppt-quality，把这些已确认材料制作成面向合作伙伴的可编辑 PPT。根据受众组织叙事，区分事实、建议和待确认条件。图表应帮助解释内容，数据图须遵循选图指南；缺少证据不要编造。使用本项目的品牌资料，并实际检查最终导出文件。

## 能力边界

这是工作方法和质量标准，不包含模型、PPT 生成引擎、字体文件、连接器、执行额度或客户模板。目标 Agent 需要有读取文件、制作或修改演示、导出与预览的相应能力。

不同模型、工具和环境的成品可能不同。不能渲染或逐页查看时，应明确标为未完成视觉验收。整页图片不能被称为完全可编辑 PPT。

本仓库不包含原始客户 PPT、客户截图、本机路径或 infographic-studio 的完整技能与设计系统。具体品牌和视觉风格请另行提供有权使用的材料。

## 更新与打包

技能核心、数据图指南和验收规则均在单个 `SKILL.md` 中，方便不支持附属引用文件的平台读取。

修改该文件后运行：

```bash
python3 build_package.py
```

只使用 Python 标准库。脚本生成 ZIP、通用指令和校验摘要，并检查不应发布的本机路径、未解析相对链接及压缩包内容。请同时审阅内容与实际使用效果，脚本检查不能代替行为验收。

欢迎通过 Issue 提供可复现问题，通过 Pull Request 改善规则。请使用虚构或已获授权公开的材料，避免上传客户原件。
